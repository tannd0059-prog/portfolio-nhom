Giải Đáp: Chạy Localhost Chung Hay Riêng Port?

Phân tích chi tiết về cơ chế vận hành nhiều thư mục website trên máy tính cá nhân (Localhost).

Cách 1: Chạy Chung 1 Port (Khuyên Dùng)

Trang tổng hợp này đã thiết kế để TẤT CẢ 6 PORTFOLIO CHẠY CHUNG TRÊN 1 PORT DUY NHẤT (Ví dụ http://localhost:5500).

Chỉ cần mở thư mục gốc port nhóm bằng Live Server trong VS Code hoặc chạy file start-server.bat. Tất cả các liên kết thành viên đều là đường dẫn tương đối và hoạt động ngay tức thì!

Cách 2: Chạy Đa Port (Multi-port Localhost)

Nếu mỗi bạn tự chạy server riêng trên máy mình:

• Có chạy chung được không? Có, hoàn toàn được! Máy tính cho phép chạy hàng chục server cùng lúc trên 127.0.0.1, miễn là số Port phải khác nhau (VD: Tân 5500, Thiên 3000, Khiêm 5501...).

• Lưu ý: Không được để 2 ứng dụng chạy cùng 1 số port cùng lúc (sẽ bị lỗi Port in use / EADDRINUSE).
